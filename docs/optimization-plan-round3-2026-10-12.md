# 第三轮：模拟交易正确性与任务体验

## 范围与依据

前两轮性能优化已提交 main。本轮优先处理写入正确性，再完善可理解的任务状态；不扩展为无期限重构。

代码检查确认 `api/paper/trades/route.ts` 在事务中读取余额/持仓，但没有显式行锁；`lib/paper/execution.ts` 用事务外的决策、余额和持仓快照计算，并在写入事务中无条件标记 executed。这属于并发风险，尚未用隔离测试证明具体触发频率。本轮必须先写可重复的并发测试，再实现并比较结果。

## 工作清单

| 优先级 | 负责人 | 实现 | 验收 |
| --- | --- | --- | --- |
| P0 | backend | 手动买卖与 AI 决策执行采用一致的事务锁顺序，在锁内读取余额、持仓和决策状态，避免并发超卖、余额负数和重复决策执行 | 隔离测试库：并发买卖、同一决策多次执行、自动/手动竞争、失败回滚、跨用户拒绝 |
| P0 | backend + frontend | 手动模拟交易支持持久幂等键，解决成功提交后响应丢失导致重复交易；校验安全整数金额和相同键不同请求 | 同键并发/重放只产生一笔交易；同键不同内容拒绝；客户端网络失败保留原键，成功后下一次交易换键；不自动重试 POST |
| P1 | frontend | 分析卡片/详情清晰解释 queued、running、failed、resume-queued；保留服务器提供的错误信息与继续入口 | 不根据猜测宣称供应商限流、排队位置或预计时间；隐藏任务/继续状态和现有模型/Token 展示正确 |
| P0 | coordinator | 审查并发实现和接口兼容，统一构建、迁移、新机器初始化与回归，记录部署前后证据 | web/worker 类型检查、生产 build、隔离数据库并发测试、Playwright mock、权限/费用/恢复回归 |

## 分工边界与接口契约

- frontend 编辑 analysis-client.tsx、portfolio/page.tsx、独立客户端辅助文件及自己的前端测试；不编辑 API、schema、共享执行逻辑。
- backend 编辑 paper trades/decision execute API、lib/paper/execution.ts、必要的新服务端辅助文件、schema 与迁移、独立并发测试；不编辑前端、admin/actions.ts 或 model-create-form.tsx。
- 新手动交易幂等契约：客户端给 `/api/paper/trades` POST 发送 `Idempotency-Key` UUID 头；服务端支持旧客户端不带键，但不能把无键请求声称为重放安全。带键请求按认证用户与组合隔离，保存可比较的请求标识及结果；相同键不同内容返回 409。保持现有 JSON 成功字段兼容。响应丢失后同一操作可显式重试原键，不能把每一次合法同内容交易都永久合并。
- backend 所需唯一约束/新增字段提供 Drizzle migration、snapshot/journal；不改历史金额或修改真实用户资产，不删除生产数据。禁止将整个交易 POST 添加通用自动重试。
- 协调者在两位执行者完成后整合共享修改和测试；保留两处原有未提交表单改动。不自动提交或推送 Git。

## 测试与部署边界

并发与交易写入测试只能使用新建的隔离数据库或明确隔离的新测试账户；优先单独数据库。复用完整迁移，结束清理仅限本测试创建的数据/数据库。不得对真实组合下单，不调用收费模型，不新建可被生产 Worker 领取的分析任务。先测后改的失败基线必须记录；不得在确认安全前让有问题的测试访问生产数据库。

部署前检查模型调用、费用快照、积分、恢复和分页未回归。完整构建通过后可更新 web。本轮执行逻辑也由 paper Worker 导入，协调者需检查运行中状态，只有安全空闲时重启原本正在运行的 paper 服务；不得中断现有模型调用或分析 Worker，不得启动原本未运行的收费服务。若暂不具备安全重启条件，明确记录待生效部分，不假称完全部署。

本轮不实施收益曲线、历史交易分页、告警中心、数据库同地域迁移。这些保留为下一轮候选；优先让交易在并发和不确定响应下保持正确。

## tmux、检查点与额度恢复

沿用 codex tmux 的 team-frontend / team-backend / team-coordinator 窗口。新批次指令、确切会话 ID、检查点和状态保存在 `var/codex-team-round3/`，旧批次证据不覆盖。协调者等待执行者完成后再调用模型。

本机 cron 每 15 分钟检查续跑；明确额度限制才重试，解析结构化恢复时间及 CLI 的本地时间提示，没有可靠时间则指数退避。普通错误暂停，不无限重试。每个角色最多 12 次额度重试，批次最长 7 天，完成后自动清除本批次 cron。无法提前精确读取账号剩余额度，不保证刷新瞬间立即执行。

查看：`python3 var/codex-team-round3/team.py status`；停止：`python3 var/codex-team-round3/team.py stop`。
